# AI Animation Lab

Workspace for planning, producing, and reviewing AI-assisted Blender animation projects.

## Project layout

- `docs/` — decisions, experiments, and retrospectives.
- `assets/` — source characters, environments, props, textures, and audio.
- `blender/` — Blender scenes, reusable assets, scripts, and renders.
- `episode-specs/` — episode briefs and production specifications.
- `output/` — exported deliverables.
- `tools/` — project utilities and automation.

The project north star and 15-second Blender/AI study plan are kept at the repository root.
